# freelance-bot
# 🤖 Multi-Functional Freelance Portfolio Telegram Bot

An interactive and feature-rich Telegram Bot built in Python using `pyTelegramBotAPI`. It serves as a digital portfolio and automated service ordering system for Python development services.

## 🔗 Live Demo
Try the bot directly on Telegram: [@ns_freelnc_bot](https://t.me/ns_freelnc_bot)

## 🌟 Key Features
- **Interactive Inline Keyboards:** 6 dynamic buttons for service selection and direct contact.
- **Multilingual Support:** English & Russian interfaces.
- **Instant Admin Notifications:** Automatically sends new client order details directly to the admin's Telegram chat.
- **Services Offered:** Telegram Bot Development, Web Scraping, Automation Scripts, Data Cleaning, and AI Integration.

## 🛠 Tech Stack
- **Language:** Python 3.x
- **Library:** `pyTelegramBotAPI` (`telebot`)
